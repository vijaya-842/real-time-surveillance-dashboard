# Real-Time Multi-Object Tracking & Surveillance Intelligence Dashboard

> M.S. Computer Science Capstone Project — University of Missouri-Kansas City (2024–2025)

## Overview
An end-to-end AI-powered video analytics platform that processes live surveillance streams in real time, transforming raw unstructured video data into structured, queryable intelligence with interactive visual dashboards for operator decision-making.

## Key Features
- **Real-Time Object Detection & Tracking** — Faster R-CNN + Siamese Networks for consistent identity persistence across video frames
- **Automated Threat Alerts** — Real-time alerts on unrecognized individuals, replacing manual reactive monitoring with a proactive data-driven system
- **Heatmap & Trajectory Analytics** — Interactive dashboards visualizing movement patterns and behavioral anomalies across time
- **Spatial Data Analysis** — Surface security insights from high-volume positional data streams

## Tech Stack
| Category | Tools |
|---|---|
| Deep Learning | PyTorch, Faster R-CNN, Siamese Networks |
| Data Processing | Python, NumPy, OpenCV |
| Visualization | Matplotlib, Interactive Dashboards |
| Collaboration | Git, Agile/Scrum (3-person team) |

## Architecture
```
Live Video Stream → Object Detection (Faster R-CNN) → Identity Tracking (Siamese Network)
       ↓
Structured Intelligence Layer → Alert Engine + Heatmap/Trajectory Dashboards
```

## Results
- Reduced threat detection time through real-time automated alerting
- Achieved consistent identity persistence across video frames
- Replaced manual monitoring with a proactive intelligence system
